# 🥔 土豆兄弟 - Potato Brothers

一个模仿土豆兄弟（Brotato）的网页版肉鸽射击生存游戏。

## 🎮 游戏特色

- **6种武器**: 手枪、霰弹枪、冲锋枪、激光枪、火箭筒、电击器
- **5种敌人**: 普通土豆、快速土豆、坦克土豆、远程土豆、自爆土豆
- **2种Boss**: 巨型土豆、土豆国王
- **20波游戏内容**: 难度逐渐递增
- **道具商店系统**: 波次间购买强化
- **升级系统**: 升级时选择属性强化
- **成就系统**: 12个成就等你解锁
- **像素风格**: 复古像素艺术风格

## 🎯 操作说明

- **WASD / 方向键**: 移动角色
- **自动射击**: 自动瞄准最近的敌人射击
- **ESC / P**: 暂停游戏

## 🚀 快速开始

### 方法一：直接打开
1. 双击 `index.html` 文件
2. 游戏将在浏览器中打开

### 方法二：本地服务器
1. 安装 Python（如果未安装）
2. 在游戏目录打开终端
3. 运行以下命令：
   ```bash
   # Python 3
   python -m http.server 8000

   # Python 2
   python -m SimpleHTTPServer 8000
   ```
4. 打开浏览器访问 `http://localhost:8000`

### 方法三：使用 Node.js
1. 安装 Node.js
2. 安装 http-server：
   ```bash
   npm install -g http-server
   ```
3. 在游戏目录运行：
   ```bash
   http-server
   ```
4. 打开浏览器访问显示的地址

## 🎨 游戏机制

### 武器系统
| 武器 | 伤害 | 射速 | 特点 |
|------|------|------|------|
| 手枪 | 10 | 中等 | 基础武器，稳定输出 |
| 霰弹枪 | 8×5 | 慢 | 近距离散射，伤害爆炸 |
| 冲锋枪 | 5 | 快 | 射速极快，倾泻火力 |
| 激光枪 | 15 | 中等 | 穿透射线，直线打击 |
| 火箭筒 | 40 | 慢 | 范围爆炸，一击必杀 |
| 电击器 | 12 | 中等 | 连锁闪电，群体伤害 |

### 敌人系统
- **普通土豆**: 基础近战敌人
- **快速土豆**: 高速低血，难以瞄准
- **坦克土豆**: 高血量护甲，移动缓慢
- **远程土豆**: 远程攻击，保持距离
- **自爆土豆**: 接近后自爆，范围伤害

### Boss系统
- **巨型土豆**: 多阶段战斗，会冲锋
- **土豆国王**: 召唤小怪，逐渐狂暴

### 道具系统
- **普通**: 白色边框
- **稀有**: 蓝色边框
- **史诗**: 紫色边框
- **传说**: 金色边框

## 📝 开发说明

### 添加新武器
1. 在 `config.js` 的 `WEAPONS` 中添加配置
2. 在 `weapon.js` 中添加射击逻辑
3. 在 `player.js` 中添加武器切换支持

### 添加新敌人
1. 在 `config.js` 的 `ENEMIES` 中添加配置
2. 在 `enemy.js` 中添加AI行为
3. 在 `wave.js` 中添加生成逻辑

### 添加新成就
1. 在 `config.js` 的 `ACHIEVEMENTS` 中添加配置
2. 在 `achievement.js` 中添加检查逻辑
